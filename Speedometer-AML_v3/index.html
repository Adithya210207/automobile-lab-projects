STM32 serial format
Send lines over UART/USB like: 1234 (ADC 0–4095), ADC=1234, or THR=45.2 (%). One value per line (\n).

Gear can be sent on the same line as the ADC value: ADC=1234,GEAR=2, where GEAR is 1=Eco, 2=Normal, 3=Sport, read from the handlebar rocker switch. When connected, gear is driven by the switch and the on-screen mode buttons are disabled.

Cruise control comes from the F/R rocker: ADC=1234,GEAR=2,CC=1, where CC is 1 when the rocker is in the R (cruise) position and 0 in F (normal). While cruise is on, throttling up raises the held speed but easing off the throttle holds the speed instead of dropping it.
