STM32 serial format
Send lines over UART/USB like: 1234 (ADC 0–4095), ADC=1234, or THR=45.2 (%). One value per line (\n).

Gear can be sent on the same line as the ADC value: ADC=1234,GEAR=2, where GEAR is 1=Eco, 2=Normal, 3=Sport, read from the handlebar rocker switch. When connected, gear is driven by the switch and the on-screen mode buttons are disabled.

Direction can be included too: ADC=1234,GEAR=2,DIR=1, where DIR is 1=Forward, 2=Reverse, read from the F/R rocker switch. Reverse caps speed at 5 km/h regardless of gear. When connected, the on-screen Forward/Reverse buttons are disabled.

Cruise status can be included too: ADC=1234,GEAR=2,DIR=1,CRUISE=1, where CRUISE is 1=engaged, 0=off. While engaged, the Arduino sends a held/latched ADC value instead of the live throttle reading, so the gauge holds steady.

Adaptive cruise (gap control) adds two more fields: ADC=1234,GEAR=2,DIR=1,CRUISE=0,ACC=1,DIST=2221, where ACC is 1=engaged, 0=off, and DIST is the live TOF sensor reading in millimetres, or -1 when no valid target is in range. ACC and CRUISE are mutually exclusive — engaging one cancels the other. While ACC is engaged, the gauge's speed is driven entirely by the gap controller in the browser, not by the throttle handle.
